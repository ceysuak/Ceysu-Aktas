UniSphere

Campus Club Management System

About the Project

UniSphere is a Django-based web application developed for managing university clubs, memberships, and events.


The system implements Role-Based Access Control (RBAC) and supports three user roles:

  • Student
  • Club Manager
  • Administrator

Documentation

For detailed instructions on how to use the system, please refer to the included User_Manual.pdf.


The User Manual covers:

  • User registration and authentication
  • Profile management
  • Club management
  • Event management
  • Administrator functions
  • Role permissions

Project Structure

  • campus_project - Main project configuration and routing
  • accounts - Authentication and profile management
  • club_management - Club and membership operations
  • event_management - Event and participant management
  • templates - Frontend templates
  • static - CSS, images, and assets
  • Database - User, club, membership, and event data

Technologies Used

Python
Django
SQLite
HTML
CSS
Tailwind CSS

Running the Project

python manage.py migrate
python manage.py runserver

Application URL:

http://127.0.0.1:8000/

To access the admin panel, add /admin to the URL.
